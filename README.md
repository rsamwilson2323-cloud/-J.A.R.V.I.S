# 🤖 J.A.R.V.I.S AI Assistant

J.A.R.V.I.S is a futuristic **browser-based AI assistant** built using **HTML 🌐, CSS 🎨, JavaScript ⚡, and Groq AI 🧠**.

The assistant provides a modern voice-enabled interface inspired by cinematic AI systems. It can respond to user queries, speak responses, open applications/websites, and interact in real time using AI-powered conversations.

---

# ✨ Features

🎤 **Voice Recognition**

* Listens to user voice commands in real time

* Converts speech into text using browser speech recognition

🧠 **AI Chat Integration**

* Connected with **Groq API** for fast AI responses

💬 **Text + Voice Responses**

* Displays responses on screen
  
* Speaks responses using text-to-speech

🌐 **Web Search & App Opening**

* Can open websites and perform browser searches

🎨 **Modern J.A.R.V.I.S Interface**

* Futuristic UI inspired by AI assistant systems

⚡ **Fast Browser-Based System**

* Runs directly in the browser without installation

# 🔑 API Setup

Open the `jarvis.html` file and paste your **Groq API Key** in the API section.

Example:

```javascript
Authorization: "Bearer YOUR_GROQ_API_KEY"
```

You can get your API key from:

https://console.groq.com/

# 🧠 How It Works

🎤 **Speech Recognition**  
Uses the browser's **Web Speech API** to capture and convert voice into text.

🧠 **Groq AI Processing**  
The user query is sent to the **Groq API** for generating intelligent responses.

🔊 **Speech Synthesis**  
J.A.R.V.I.S replies using browser text-to-speech functionality.

🌐 **Browser Automation**  
Can open websites, perform searches, and execute assistant commands.
